# Code of Conduct

GreatSales CRM is a proprietary product built by a small, professional team. This
document sets the expectations for everyone contributing to it.

## Our standards

We expect all contributors to:

- Treat colleagues with respect, patience, and good faith.
- Give and receive code review as a discussion about the work, not the person.
- Be clear and honest about status — report failures, skipped steps, and unknowns
  plainly.
- Ask when unsure, especially around security, tenant data, and migrations.
- Assume competence and communicate directly and kindly.

Unacceptable behavior includes harassment, discrimination, personal attacks,
sharing others' private information, and any conduct that would reasonably make a
teammate feel unsafe or unwelcome.

## Handling confidential material

This is a commercial, closed-source codebase governed by [LICENSE.md](LICENSE.md).
All source, schemas, customer data, and internal documentation are confidential:

- Do not share code, credentials, or tenant data outside the authorized team.
- Do not use production tenant data for testing or demos.
- Follow [SECURITY.md](SECURITY.md) for anything touching authentication, tenant
  isolation, or secrets.

## Scope

This Code applies to all project spaces — the repository, reviews, issues,
internal chat, and any venue where you represent the project.

## Reporting

Raise concerns about conduct or confidentiality privately to the project owner at
**study@rjpinfotek.com**. Reports are handled discreetly and in good faith.
Maintainers may remove access or take other appropriate action in response to
violations.
